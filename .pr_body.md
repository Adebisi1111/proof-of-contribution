## Summary

Submits **ProofOfContribution** for the GenLayer Intelligent Contracts track: non-transferable on-chain developer reputation rated by an independent AI validator committee.

## What it does

A developer submits a public documentation URL or pull request plus a rubric. The contract runs `gl.vm.run_nondet(leader_fn, validator_fn)`: the leader fetches the artifact and rates it 1–5, and **each validator independently fetches the same artifact and re-rates it**, agreeing only on an exact integer match. On disagreement the round records nothing.

Ratings aggregate into a permanent profile keyed to the developer's own address — non-transferable by construction — with a rank tier (NEWCOMER → NOVICE → CONTRIBUTOR → EXPERT → LEGEND) gated on a minimum review count.

## Why it qualifies

- **Real consensus logic** — leader/validator where validators independently re-fetch and re-rate, not a model-knowledge wrapper
- **Exact comparison** — integer 1–5 rating, no fuzzy band. Deliberately avoids `gl.eq_principle.strict_eq` over LLM output, which does not enforce cross-validator equality for non-deterministic values on this network
- **Clear state design** — parallel `TreeMap[str, scalar]` keyed by address and review id
- **Verified on-chain** — 18 assertions pass
